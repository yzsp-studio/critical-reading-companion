## 🇨🇳 中文

把深度新闻、长评论、政策解读或宣传文案等非学术公共文本，转成一张便于理解、可追溯的阅读地图。它先忠实重建作者最强版本的论证（steelman），再逐环评价证据、推理与隐藏前提，把逻辑漏洞、情绪煽动和证据缺失标到原文位置。还会补充替代解释、核查关键事实，让每个结论都能回溯到文本本身。适用于判断一篇文章是否可信、拆解宣传手法、写观点文前自检论证是否稳固，以及为行动决策找依据。

### ✨ 能做什么

- 重建论证链：把散乱叙述拆成前提 → 证据 → 结论，逐环标注
- 先公平呈现（steelman）再评价，不靠找错代替批判
- 识别隐藏前提与逻辑谬误，指出情绪煽动与证据缺失
- 补充替代解释、核查关键事实，让结论可追溯
- 输出可追溯的阅读地图，服务可信度判断、宣传分析与写作自检
- 不替用户裁定立场，批判与站队分开

## 🇬🇧 English

Turns deep news, long-form reviews, policy explainers and promotional copy — any non-academic public text — into a traceable reading map. It first rebuilds the author's strongest version of the argument (steelman), then audits the evidence, the reasoning and the hidden premises behind each claim. Logical gaps, emotional manipulation and unsupported assertions are flagged and traced back to their location in the text. It also adds alternative explanations and fact-checks key claims, so every conclusion can be traced to the source. Useful for credibility calls, dissecting propaganda techniques, self-checking your own op-ed, and grounding a decision in evidence.

### ✨ What it does

- Rebuilds the argument chain: premise → evidence → conclusion, ring by ring
- Steelman-first reading, then a quality verdict instead of mistake-hunting
- Flags hidden premises, logical fallacies and emotionally loaded claims
- Adds alternative explanations and fact-checks the key claims
- Returns a traceable reading map for credibility calls, propaganda analysis and self-review
- Keeps critique separate from taking a side for the reader
